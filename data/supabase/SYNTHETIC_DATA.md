# Synthetic data

Every CSV in this folder is synthetic: a fictional fintech and fictional vendors, generated by `src/generate.py` with seed 20261119. The files have no comment line so that Postgres `COPY` and the Supabase importer can load them. The commented originals are in `data/processed/`.

The only real-world values are the public list prices in `benchmarks.csv` (with source URL and as-of date).
